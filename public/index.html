    ABOUT THE PROJECT
    一份有数据的快乐研报。
    McFinance 是基于麦当劳官方 MCP 的独立参赛作品，用研究报告的形式，观察自己的日常消费。
    01 / 真实依据
    每条结论均可回溯到订单。退款与取消订单不计入消费，缺失原价不估算优惠。
    02 / 轻松表达
    拿金融黑话开个玩笑，给日常消费一点仪式感；评级只是样本观察。
    03 / 你的掌控
    本地运行，Token 仅在服务内存。可导入 JSON、查询账本、导出 SVG 与 Markdown。
    本项目不代表麦当劳官方。仅用于消费记录与娱乐，不构成财务或健康建议。查看比赛 ↗
